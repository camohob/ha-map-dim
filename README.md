# ha-map-dim

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/camohob/ha-map-dim)

Плагин для [Home Assistant](https://www.home-assistant.io/): делает карту
Lovelace (`type: map`) удобной для семьи.

- **изоляция выбранного человека** — при выборе человека на карте виден
  только его маршрут (в родном градиенте HA), маршруты остальных скрыты;
  сброс выбора возвращает все маршруты;
- **история маршрутов за период** — форма в панели карты: заготовки
  (`Сейчас`, `Сегодня`, `Вчера`, `Позавчера`, `3 дня`, `Неделя`) и
  произвольный период «с … по …»; исторические треки рисуются родными
  слоями карточки и подчиняются тому же правилу скрытия чужих.

Скрипт для панели «Карта» в Home Assistant (Lovelace, панельный view с картой).
Когда на карте выбран человек/устройство:

- **его маршрут остаётся в родном виде HA** (градиент 0.2 → 1.0 по возрасту
  точек — прозрачность не меняется);
- **маршруты всех остальных полностью скрываются** (прозрачность 0).

Если никто не выбран — все маршруты в обычном виде HA.

## История маршрутов

Форма встроена в штатную панель карты «Люди/Устройства» (hui-map-overview,
внизу панели, под списком) и оформлена переменными темы HA — тёмная/светлая
тема подхватываются автоматически. Форма видна только вместе с карточкой
карты. В ней:

- **заготовки**: `Сейчас` (живой режим, поля показывают сегодняшний день),
  `Сегодня`, `Вчера`, `Позавчера`, `3 дня`, `Неделя` — заготовка
  проставляет свои даты в поля «с … по …»;
- **произвольный период** «с … по …» — маршруты за диапазон целиком;
  если заполнено только «с» — с этой даты по «сейчас»; только «по» —
  этот день. Редактирование полей перекрывает заготовку (селект
  возвращается на `Сейчас`).

### Откуда берётся история

Маршруты за период берутся из базы recorder через REST `history/period`.
Особенность HA: для сущностей `person.*` в базу пишутся только смены
состояния (зоны «Дома»/«Школа»/…), плотный GPS-трек из живого потока в
базу не попадает. Поэтому модуль берёт историю у **трекеров-источников**
людей (`person/list` → `device_trackers`) и подмешивает её в маршрут
человека — исторический трек получается той же плотности, что и живой.
Если у человека нет трекера с записью в базе, останутся только смены зон.

При уходе с карточки карты режим истории сбрасывается.

Исторические маршруты рисуются на той же карте родным видом HA (градиент
по прогрессу дня: старые точки бледнее, новые ярче) и подчиняются тому же
правилу: у выбранного виден его маршрут, у остальных — ничего. При выходе
в `Сейчас` живые маршруты возвращаются. Данные берутся из REST API
`/api/history/period/...` — глубина доступной истории зависит от retention
recorder'а HA (по умолчанию 10 дней).

## Как установить

1. Скопируйте `ha-map-dim.js` в папку `/config/www/` вашего HA
   (например, через File editor, Studio Code Server или Samba):
   путь файла должен стать `/config/www/ha-map-dim.js`.

2. В HA: **Настройки → Дашборды → Ресурсы → Добавить ресурс**
   - URL: `/local/ha-map-dim.js`
   - Тип: **JavaScript Module**

3. Жёстко обновите страницу карты (Ctrl+F5). Готово.

## Как настроить

По умолчанию скрытие — полное (прозрачность 0 у чужих маршрутов). Поведение
v4 не имеет настроек; версия v3 (приглушение до заданного предела) доступна
в истории проекта.

## Как это работает (кратко)

Карта (ha-map) рисует маршруты движком MapLibre GL — это не SVG/CSS, а слои
`ha-map-path-N-lines` на canvas. Прозрачность каждого отрезка задаётся
свойством `opacity` фичи (родной градиент 0.2 → 1.0 по возрасту точек).

Скрипт:

1. Дожидается регистрации `ha-map` и `hui-map-card` (хук на
   `customElements.define`) и оборачивает их методы.
2. Оборачивает `ha-map.prototype._drawPaths` и проксирует `engine.addPath`
   (чистый метод берётся с прототипа класса движка): перед отрисовкой
   пересчитывает `opacity` отрезков — у невыбранных ставит 0 (скрытие),
   выбранный не трогает.
3. «Выбранный» определяется по флагу `selected` в `ha-map.entities`
   (фолбэк на URL не нужен — карточка сама ставит флаг).
4. При смене выбора (`hui-map-card.updated`, `_overviewSelected`)
   просит карту перерисовать пути и пересчитать видимость исторических
   маршрутов — переключение мгновенное, без перезагрузки страницы.
5. История: REST `history/period` → состояния `{s, a, lu}` → родной
   конвертер карточки `card._getHistoryPaths(...)` → пути формата
   `{name, color, gradualOpacity, points:[{point, timestamp}]}` →
   конвертация в движковый формат `{color, segments:[{opacity, points}],
   markers:[{location, opacity, tooltipHtml}]}` (градиент по индексу точки,
   тултипы через `haMap._computePathTooltip`) → отрисовка через чистый
   `engine.addPath` (мимо прокси скрытия). Живые пути на время истории
   скрываются целиком (режим `map.__haMapDimHistory`).

## Ограничения / нюансы

- Матчинг «выбранный ↔ маршрут» идёт по имени (friendly_name).
  Два объекта с одинаковым именем подсветятся одновременно.
- Сущности без истории (пустой маршрут) просто остаются пустыми.
- Патч живёт на прототипах и переживёт обновления HA, пока сохраняются
  имена методов `_drawPaths` / `updated`; при их смене скрипт просто
  бездействует (без ошибок).
- Работает и на обычных карточках `type: map` (без панели выбора) —
  там нет выбора, поэтому ничего не меняется.
